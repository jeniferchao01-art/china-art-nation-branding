# ART DIPLOMACY AND NATION BRANDING

This folder is a static-site conversion of a WordPress.com WXR export.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload **all files and folders in this directory** to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide a `github.io` address for the site.

## Important before closing WordPress

The export contained 41 media attachment records, but not the image files themselves.
Open `MEDIA_TO_DOWNLOAD.md` and make sure you have copies of those images. At present the converted pages may still load some images from the old WordPress URLs.

Also test Contact Us carefully: WordPress-native forms cannot process submissions on GitHub Pages because GitHub Pages is static hosting.
